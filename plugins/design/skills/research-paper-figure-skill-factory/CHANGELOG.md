# Changelog

## 2.0.5 - 2026-05-07

- Added a visual-structure-as-image gate for generated specialized skills.
- Required generated skills to embed a saved reference or non-target visual-structure concept/modeling image when text turns explain layout skeleton, panel choreography, module topology, arrow grammar, candidate-board structure, second-round optimization geometry, or final content architecture.
- Prohibited prose-only, bullet-only, ASCII, Mermaid, SVG, or code-rendered visual-structure explanations as the sole representation in generated skill text replies.
- Required generated skills to embed saved reference or non-target concept/modeling example images during abstract visual decision text turns, or record missing state and repair action.
- Required a diverse first-round candidate board followed by P6b/P6b-IMAGE/P6c paper-local second-round optimization before P7 final prompt construction.
- Added state fields and release checks for `visual_structure_image_required`, `visual_structure_image_status`, `visual_structure_image_role`, `visual_structure_image_trigger_reason`, `concept_example_*`, `best_practice_divergence_*`, `second_round_candidate_batch_id`, and `selected_second_round_candidate`.
- Preserved target-paper candidate/final/revision image isolation: paper-specific structure previews still belong in P5/P6b-IMAGE/P8 `IMAGE_ONLY` turns.
